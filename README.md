# 毛主席诗词演讲稿生成器

把毛泽东诗词按创作年代串成一篇可直接上台朗诵的「他说」体演讲稿。

单文件 HTML，零依赖，双击即用。

---

## 它是什么

面向红色主题朗诵、演讲、主题党日、校园比赛场景的稿件生成器。选定诗篇与时长后，输出一篇以「他说——」串联的朗诵稿：诗句取自全编诗库，按创作年份排布，可带舞台提示，结尾有本地呼应。

## 主要能力

- **全编诗库 76 条**：正编 39 篇 + 副编 25 篇 + 附录 10 篇，另含源流 2 条
- **双生成模式**
  - AI 模式：接入大模型流式生成，支持 6 家供应商，可随时中止
  - 离线模式：无 API Key 也能出稿，内置复刻稿与通用稿两套模板
- **七时代段自动分组**：少年远行 → 红潮初涌 → 星火长征 → 烽火决战 → 换了人间 → 只争朝夕 → 千古对话，跨组自动补过渡句
- **时长自适应**：3 / 4 / 5 / 6 分钟对应诗行预算，超量自动摘句（首句 + 结句优先）
- **诗库浏览**：标签筛选、关键词搜索、全选 / 清空、实时时长预估
- **复制与下载**：含 `file://` 环境下的剪贴板降级方案

## 快速开始

**在线使用**（无需下载）：<https://bzdoit.github.io/mao-poetry-speech/>

**本地使用**：

1. 双击打开 `毛主席诗词演讲稿生成器.html`
2. 左侧勾选诗篇，或直接点预设
3. 选时长、场合、是否带舞台提示
4. 点「生成」

离线模式无需联网、无需安装任何东西。要用 AI 模式，在设置里填一家供应商的 API Key（仅存浏览器 localStorage，不上传）。

### 运行全书回归核对

`tools/verify_poems.js` 依赖底本解析数据 `tools/book_items.json`。该文件是《毛泽东诗词全编鉴赏》EPUB 的解析产物，**因版权原因未随本仓库分发**。

如需自行核对：

1. 自备该书 EPUB
2. 解析出 74 篇诗条目，写入 `tools/book_items.json`（字段：`title` / `year` / `verse` / `notes`）
3. 运行：

```bash
node tools/verify_poems.js
```

退出码 `0` = 全部通过，`1` = 有未命中，`2` = 未找到底本。

### 关于「男儿立志出乡关」

这句并非毛泽东原创。它出自日本江户末期僧人**月性**（1817—1856）《将东游题壁》：

> 男儿立志出乡关，学若无成不复还。
> 埋骨何期坟墓地，人间到处有青山。

1910 年秋，17 岁的毛泽东离家赴湘乡求学，据此改写为《七绝·呈父亲》：

> 孩儿立志出乡关，学不成名誓不还。
> 埋骨何须桑梓地，人生无处不青山。

旧题作「改西乡隆盛诗」，据考证原作者实为月性，西乡隆盛只是传诵者。本库将原诗与改作分列两条，朗诵稿中会明确交代源流，不会把日本僧人的诗误植到毛泽东名下。
