# 他说

（灯光收束，一人独立，声音由远及近）

> 【可选·源流开场增强】原视频直接以《呈父亲》开场；仿写时若想保留"男儿立志出乡关"这句精髓，可在开场前加四句月性原诗并明确交代源流：
> "故事要从一位日本僧人说起。江户末期，僧人月性离开故乡，在壁上题下四句——
> 男儿立志出乡关，学若无成不复还。
> 埋骨何期坟墓地，人间到处有青山。
> （停顿）半个多世纪后，这四句跨海而来，落进湖南一个十七岁少年的心里。"
> 随后接下文。注意：原诗必须注明"日本僧人月性"，不得说成毛泽东所作。

1910年，临行前夜，他在父亲的账簿里，夹下了一首改写言志的诗。他写下——

孩儿立志出乡关，学不成名誓不还。
埋骨何须桑梓地，人生无处不青山。

（停顿）青涩的少年走出了韶山冲，破晓的晴空上，亮起了一抹红色。

橘子洲头，他叩问苍茫大地。他说——

指点江山，激扬文字，粪土当年万户侯。

他誓要将这天地，换一个颜色。

会昌城外，晨光熹微。他知道，即将面临一场惊世的远征，却没有分毫磨灭斗志。他说——

东方欲晓，莫道君行早。
踏遍青山人未老，风景这边独好。

六盘山上，红旗漫卷西风。他说——

今日长缨在手，何时缚住苍龙？

革命的星火，再次照亮中原。金陵城头，蒋家王朝覆灭在即。他心潮澎湃，却不忘自省。他说——

钟山风雨起苍黄，百万雄师过大江。
虎踞龙盘今胜昔，天翻地覆慨而慷。
宜将剩勇追穷寇，不可沽名学霸王。
天若有情天亦老，人间正道是沧桑。

晚年，面对风云变幻的国际局势，他写下了直面风云的战斗宣言。他说——

多少事，从来急；天地转，光阴迫。
一万年太久，只争朝夕。
四海翻腾云水怒，五洲震荡风雷激。
要扫除一切害人虫，全无敌。

他对人民，有着最真挚的情感。

（声音压低，再骤然扬起）人民说：毛主席万岁！

他说——人民万岁！

他说——

遍地哀鸿满城血，无非一念救苍生。

他说——

春风杨柳万千条，六亿神州尽舜尧。

他说——

俱往矣，数风流人物，还看今朝！

（长停顿）五千年太近，五十年太远。

今天，每当我站在齐齐哈尔的土地上，望见嫩江，我的耳边，仿佛又响起那荡气回肠的声音——

（握拳，层层渐强）战无不胜的毛泽东思想，像强劲的东风，吹遍四海五洲！让我们欢呼吧！让我们歌唱吧——

数风流人物，还看今朝！（定格）

## 引用出处与背景

1. 《七绝·呈父亲》（1910年，**青年改作，非原创**）：改写日本僧人月性《将东游题壁》，旧题"改西乡隆盛诗"；未收入官方《毛泽东诗词集》与《全编鉴赏》，叙事用"写下/改写"，不用"创作"。
2. 《沁园春·长沙》（1925年）：重游橘子洲，"谁主沉浮"之问。
3. 《清平乐·会昌》（1934年）：长征前夕，"风景这边独好"。
4. 《清平乐·六盘山》（1935年）：长征将尽，"何时缚住苍龙"。
5. 《七律·人民解放军占领南京》（1949年）：渡江战役解放南京。
6. 《满江红·和郭沫若同志》（1963年）："只争朝夕""全无敌"。
7. "人民万岁"：1949年开国大典天安门城楼。
8. 《七律·重庆谈判》（1945年秋，**辑逸诗**）：未收入1996年《毛泽东诗词集》；经吴正裕版本考证（据1947年《大公报》、1949年《立报》及胡绳见证，《党的文献》2016年第6期）确认为毛泽东重庆谈判期间所作，"遍地哀鸿"为其末联，可正常引用。
9. 《七律二首·送瘟神》其二（1958年）："六亿神州尽舜尧"。
10. 《沁园春·雪》（1936年）：压卷文眼"还看今朝"。

## 朗诵处理建议

1. 六段情绪：少年清亮 → 远征沉毅 → 决战铿锵 → 宣言凌厉 → 人民深情（最大反差）→ 今朝全开，一段强过一段。
2. 每个"他说——"前沉半拍，诗句拉开字距、咬字如钉；叙事句则连贯口语化，形成"讲"与"吟"的对比。
3. "人民万岁"一处先把声音压到最低、再拔到最高，全场爆发点。
4. 结尾"还看今朝"四字一字一顿，握拳定格两秒再收。

## 还原说明与听辨不确定处（勿写进正式稿）

- 开场年份视频口播疑似读作"1916年前后"，与该诗通行系年1910年不符，正式稿用1910年。
- 结尾本地改编句（"站在齐齐哈尔……望见……""毛泽东思想……全球"）现场收音含糊，本稿以语意补全，非原话逐字记录。
