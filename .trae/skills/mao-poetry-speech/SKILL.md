# 毛主席诗词「他说」体演讲稿生成

为演讲比赛、主题党日、校园/单位活动撰写以毛主席诗词为骨架的朗诵稿/演讲稿。标志性文体：叙事者用第三人称"他"推进时代画面，以"他说——"逐次引出诗句，最后转第一人称结合本地地标升华（俗称"他说体"，源自网络流传的同名朗诵作品）。

## 触发场景

- 用户要红色主题/爱国主义/党史主题的演讲稿、朗诵稿、主持词串词
- 用户明确提到"毛主席诗词""教员诗词""他说体""诗词串烧朗诵"
- 用户给了类似抖音/B站朗诵视频要求仿写

## 工作流程

1. **先问清 4 个参数**（用户已说的不重复问）：
   - 场合（演讲比赛 / 主题党日 / 校园 / 团建汇演）
   - 时长（3-6 分钟；舞台朗诵按约 230-240 字/分钟估算：3分≈700字，4分≈950字，5分≈1200字，6分≈1450字）
   - 城市/单位 + 本地地标意象（结尾呼应用，如齐齐哈尔·嫩江·鹤乡、延安·宝塔山、长沙·橘子洲）
   - 是否要舞台提示（停顿/重音/手势）和朗诵者身份
2. **选诗**：读取 [references/poem-library.md](references/poem-library.md)（全编本：正编39＋副编25＋附录10共74篇；另保留通行改作《七绝·呈父亲》与其所本的月性原诗《将东游题壁》各1首，两篇均非该书篇目），按场合从情绪主线选 5-10 首，严格按创作年份排序。经典复刻组合见 [references/formula.md](references/formula.md)。
3. **写稿**：严格按 [references/formula.md](references/formula.md) 的结构公式与红线写作。
4. **自检**：交稿前必须逐条过一遍文末【交稿验收清单】，任何一条不过就改到过为止。
5. **输出格式**：标题 → 正文（诗句独立成段）→ 若要舞台提示则以中文括号插入正文 → 文末附【引用出处与背景】和【朗诵处理建议】（3-5 条情绪/节奏建议）。

## 红线（必须遵守）

- **诗句只能引用诗词库中已核验的原文**；库里没有的句子，绝不凭记忆编造，宁可换一首或告知用户查证后再用。
- 不虚构创作背景、年份、历史事件；背景只用库里一句话版本，拿不准就不写细节。
- 辑逸/附录诗（库中标〔辑逸／未入1996年官方集〕，共10首：祭黄陵文、重庆谈判、仿陆游、读报四首、改鲁迅诗、读《封建论》）作者生前未入正式诗词集，文字各本间或有差异，**一律照库中所录文本引用**；其中《七律·重庆谈判》有吴正裕版本考证与胡绳见证，可正常使用并在出处注明校订依据，**严禁当成伪作/托名作品警告用户，也严禁把传抄异文（如"无屎""为群众"）当原文**。读报诗等政治讽刺题材默认不进学生/正式庆典稿，除非用户明确要。
- 改作诗（库中标注"青年改作"，目前仅《七绝·呈父亲》）系青年毛泽东改写日本僧人月性《将东游题壁》，**非其原创、未入官方集**；可按通行改作文本引用，但叙事只能说"他写下/改写言志"，不得说"他创作"。
- 库中〔源流·外国原诗〕月性《将东游题壁》（"男儿立志出乡关"）**不是毛泽东作品**：只用于与《呈父亲》并置交代源流，叙事须写明"日本僧人月性原诗"，绝不可安到毛泽东名下；用户爱用这一句作开场时，用"原诗→少年改写"的双层结构。
- 两首《贾谊》原书无系年，不得编造创作年份。
- 不写成政治评论或现代口号堆砌；文体是文学朗诵稿，语言要凝练、能上口。

## 交稿验收清单（每条必过）

- [ ] **逐字核验**：稿中每一句诗都与 poem-library.md 原文逐字一致——无错字、无漏字、无调换字序、无张冠李戴；库里没有的句子一律不出现。
- [ ] **系年正确**：诗词严格按创作年份从早到晚；两首《贾谊》无系年就不写年份，月性《将东游题壁》只写"约1844年前后"，不得写成确年。
- [ ] **改作用语**：《七绝·呈父亲》只说"他写下/改写言志"，绝不说"他创作"；月性原诗出现时必须写明"日本僧人月性原诗"，不安到毛泽东名下。
- [ ] **辑逸/附录合规**：《七律·重庆谈判》照库中校订本引用并注明"未收入1996年《毛泽东诗词集》，据吴正裕校订本"，不当伪作警告；读报诗、改鲁迅诗、读《封建论》等政治讽刺诗不进学生/庆典稿，除非用户明确要求。
- [ ] **时长达标**：正文按约 230-240 字/分钟估算符合约定时长（3分≈700字，4分≈950字，5分≈1200字，6分≈1450字）；每处引用 2-6 行，长诗不全文搬运。

工具侧的诗句回归（74 篇 223 行逐字比对）可随时运行：`node tools/verify_poems.js`（退出码 0 为通过）。
